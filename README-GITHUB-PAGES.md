# YCE Geradores de Energia — site estático

Este pacote contém o site completo pronto para publicação no GitHub Pages.

## Publicar

1. Crie ou abra o repositório GitHub do site.
2. Extraia este ZIP e envie **o conteúdo desta pasta** para a raiz do repositório (o `index.html` deve ficar na raiz).
3. Em **Settings → Pages**, escolha **Deploy from a branch**, selecione a branch principal e a pasta **/(root)**.
4. Salve e aguarde a publicação do GitHub Pages.

O pacote inclui as páginas, estilos, scripts, imagens, vídeos e o arquivo `.nojekyll` necessários para o site.
